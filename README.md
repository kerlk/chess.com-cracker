# Chess.com cracker

Расширение для анализа позиций и подсказки лучших ходов на chess.com.

Интеграция нейросети Maia может работать нестабильно - в случае отвала модуля анализа необходимо перезагрузить страничку chess.com. Баг зафиксирован, будет исправлен в стабильной версии 1.0.3.

## Установка

1. Скачайте или склонируйте репозиторий:
   ```
   git clone https://github.com/kerlk/chess.com-cracker.git
   ```
2. Откройте `chrome://extensions/` в браузере.
3. Включите **Режим разработчика** (Developer mode).
4. Нажмите **Загрузить распакованное расширение** (Load unpacked).
5. Выберите папку с проектом.
6. Готово — иконка расширения появится на панели.

## релизы:

1.0.0 - добавлен stockfish 19 (около 3600 эло), работающий на анализ позиции (полоска анализа) и подсказки для ходов (доступно только на доске chess.com. Создан фронтент расширения - копия доски на отдельной странице, а так же встраиваемые в код страницы chess.com элементы (заточено под интерфейс партий против ботов, обозначения стрелок встроены в участок страницы, недоступный в катках против игроков). Версия не была опубликована на гитхаб. Баги: полоска анализа считает ход для белых даже во время хода чёрных. Рокировка не работала. Исправлено в бета 1.0.3

1.0.1 - добавлены стрелки анализа на доске расширения. Добавлен "режим стримера", отключающий абсолютно все обозначения добавляемые читом в код страницы. Все кнопки в режиме стримера переносятся на отдельную страницу расширения, что позволяет записывать окно браузера с chess.com без визуальных улик чита. Добавлена кнопка рокировки - пока рокировка исключительно ставится вручную. Количество подсказок увеличено до трёх - так пользователь сможет использовать менее сильные ходы чтобы меньше палиться. Была опубликована как 1.0.0 по ошибке. Первые правки для игры против игроков. Исправлены обозначения стрелочек на страницах, отличных от страниц при игре против ботов. Поддержка отдела с шахматными задачками не добавлена намеренно. Баги/недочёты: правки интерфейса при игре против ботов отличаются от правок интерфейса в игре не против ботов. Будет исправлено в версии 1.0.4.

1.0.2 - была добавлена тестовая поддержка самой человечной шахматной нейросети Maia (1500-2800 эло по моей оценке). С ней обнаружение чита становится околоневозможным. Maia была встроена напильником и всеми волшебными словами великого русского языка. Ожидаются проблемы на MacOS, у меня нет возможности провести отладку на этой операционной системе, модель работает на GPU (или на CPU в случае возникновения проблем). версия была опубликована как 1.0.0.

1.0.3 бета - код научился читать ходы из таблички ходов. Исправлена полоска анализа - теперь она знает чей сейчас ход и рассчитывает правильную позицию после каждого хода, а не через ход. Анализ выглядит немного подлагивающим из-за задержки в определении хода. Если смогу, исправлю к 1.0.4. Кнопка рокировки теперь нажимается и сбрасывается автоматически. На данный момент осталась как инструмент отладки и предохранитель. Maia поломался - из-за исправлений в код определения положения доски движок может потерять положение фигур на доске. Пытался исправить ошибку перезагрузкой движка анализа, но потерпел фиаско - вероятнее всего проблема в тех сложных посредниках, которые мне пришлось добавить для того чтобы подружить Maia и самописную доску. На данный момент лечится перезагрузкой страницы chess.com. Будет исправлено к стабильной 1.0.3.
